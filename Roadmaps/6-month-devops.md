# 6-Month DevOps Roadmap

## 🎯 Overview

This structured roadmap takes you from beginner to job-ready DevOps engineer in 6 months with daily study goals and weekly milestones.

## 📅 Month 1-2: Foundation (Weeks 1-8)

### Week 1-2: Linux Fundamentals
**Daily: 2-3 hours**

- [ ] Day 1-2: File system navigation, permissions
- [ ] Day 3-4: User management, process management
- [ ] Day 5-6: Text processing (grep, sed, awk)
- [ ] Day 7-8: Package management (apt, yum)
- [ ] Day 9-10: Systemd services, cron
- [ ] Day 11-14: Practice exercises, build a web server

**Milestone**: Configure a production-ready nginx server

### Week 3-4: Networking Basics
- [ ] OSI model, TCP/IP
- [ ] DNS, DHCP, NAT
- [ ] Firewalls (iptables, ufw)
- [ ] SSH configuration and key management
- [ ] Load balancing concepts

**Milestone**: Set up SSH bastion with key-based auth

### Week 5-6: Git & Version Control
- [ ] Git basics (add, commit, push, pull)
- [ ] Branching strategies (GitFlow, trunk-based)
- [ ] Pull requests and code review
- [ ] Merge conflicts resolution
- [ ] Git hooks

**Milestone**: Contribute to an open-source project

### Week 7-8: Scripting
- [ ] Bash scripting fundamentals
- [ ] Python basics for automation
- [ ] Variables, loops, conditionals
- [ ] Functions and error handling
- [ ] File operations and APIs

**Milestone**: Write an automation script (log analyzer)

## 📅 Month 3-4: Core DevOps (Weeks 9-16)

### Week 9-10: Docker
- [ ] Container concepts
- [ ] Dockerfile writing
- [ ] Docker Compose
- [ ] Multi-stage builds
- [ ] Docker networking and volumes

**Milestone**: Containerize a multi-tier application

### Week 11-12: CI/CD
- [ ] CI/CD concepts
- [ ] GitHub Actions
- [ ] Pipeline stages (build, test, deploy)
- [ ] Secrets management
- [ ] Artifact management

**Milestone**: Build complete CI/CD pipeline

### Week 13-14: Infrastructure as Code
- [ ] Terraform fundamentals
- [ ] Resources, variables, outputs
- [ ] State management
- [ ] Modules
- [ ] Best practices

**Milestone**: Deploy AWS infrastructure with Terraform

### Week 15-16: Cloud (AWS)
- [ ] EC2, VPC, Security Groups
- [ ] S3, RDS
- [ ] IAM roles and policies
- [ ] CloudWatch basics
- [ ] Cost management

**Milestone**: Deploy scalable web application on AWS

## 📅 Month 5-6: Advanced (Weeks 17-24)

### Week 17-18: Kubernetes Basics
- [ ] K8s architecture
- [ ] Pods, Deployments, Services
- [ ] ConfigMaps, Secrets
- [ ] Local cluster (minikube/kind)

**Milestone**: Deploy app to Kubernetes

### Week 19-20: Kubernetes Operations
- [ ] Helm charts
- [ ] Ingress controllers
- [ ] Horizontal Pod Autoscaling
- [ ] Resource management
- [ ] Troubleshooting

**Milestone**: Production-ready K8s deployment

### Week 21-22: Monitoring & Observability
- [ ] Prometheus basics
- [ ] Grafana dashboards
- [ ] Log aggregation (Loki/ELK)
- [ ] Alerting setup
- [ ] SLOs and SLIs

**Milestone**: Complete monitoring stack

### Week 23-24: Production Practices
- [ ] Disaster recovery
- [ ] Backup strategies
- [ ] Incident response
- [ ] On-call practices
- [ ] Portfolio projects

**Milestone**: Complete 3 portfolio projects

## ✅ Weekly Checklist

Each week:
- [ ] Complete theory content
- [ ] Hands-on labs
- [ ] Document learnings
- [ ] Update portfolio
